# **App Name**: MB Focus

## Core Features:

- Customizable Grocery List: Users can freely enter grocery item names and quantities, then mark them as purchased in the list view. Enhances the existing 'Mercado' module.
- AI-Powered Grocery List Suggestions: An AI tool that suggests grocery items based on historical shopping patterns or common user preferences, simplifying list creation.
- Advanced Task Management: Create, prioritize, and track tasks with due dates, offering overdue and due-today indicators. Refines the 'Tareas' module.
- Financial Bill Tracking: Manage and track bills (e.g., credit card, rent, utilities) with amounts, due dates, categories, and payment status, including overdue alerts.
- Daily Habit Tracker: Users can set and log daily habits, visualize streaks, and foster consistent personal development.
- Intuitive Calendar View: A calendar module that displays upcoming tasks and bill due dates for better time and commitment planning.
- Simple Note Taking: Create and manage quick notes and ideas with titles and free-form text, accessible from a central view.
- Secure User Authentication: Allow users to register and log in securely with email and password, and manage their account.
- Social Account Integration: Enable seamless login and registration using Google and Facebook accounts for user convenience.
- Superuser Administration Dashboard: A dedicated, restricted access panel for the superuser to manage application settings, monitor system health, and oversee user data.
- User Engagement Analytics: Display graphical insights into application usage, including login counts, total registered users, and interaction metrics.

## Style Guidelines:

- Primary interactive color: A deep, energetic red (#E53935) to signify action and importance.
- Background color: A soft, warm yellow (#FFFDE7) to create a pleasant and inviting atmosphere.
- Accent color: A vibrant orange (#FF9800) for highlights, calls to action, and visual emphasis, complementing the red and yellow.
- Body and headline font: 'Inter', a grotesque-style sans-serif for its modern, objective, and neutral appearance, ensuring high readability across all content.
- Use minimalist line icons throughout the application, consistent with the clean aesthetic and avoiding visual clutter for better focus.
- Design a memorable and recognizable logo for 'MB Focus' that visually represents its core functions (e.g., organization, productivity) using the red, orange, and yellow palette.
- Emphasize clean, structured layouts with ample white space, prioritizing clear information hierarchy and intuitive navigation for productivity tasks.
- Incorporate subtle and quick transition animations, particularly on item additions/removals and tab changes, to enhance responsiveness without being obtrusive.
